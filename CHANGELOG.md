# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии по [SemVer](https://semver.org/lang/ru/).

## [0.3.0] — 2026-09-06

### Добавлено

* **`set_store` — выбор конкретного магазина внутри региона.** Раньше сессия
  висела на магазине по умолчанию, и `stock_in_current_store` относился не к
  тому месту, куда человек собирается ехать. Штатная ручка сайта
  (`POST /store-finder/pos`) отвечает `405`, поэтому клиент пробует несколько
  стратегий подряд и сверяется с POS-селектором после каждой; рабочая — кука
  `currentPOS`, она же переживает перезапуск сервера. Способ, который прижился,
  возвращается в поле `method`, а при полной неудаче — весь список попыток.

### Исправлено

* **Адрес магазина в `find_stores` терял улицу.** `/store-finder` кладёт её в
  `address.line1`, а не в корень объекта, как `/stores/<POS>/json` — в выдаче
  оставалось одинокое «г. Москва».
* **`promotions` в карточке товара — сотня `null` и мусор.** Теперь без пустых,
  без дублей и без строк с потерянной кириллицей (`???????? ?????`), которую
  бэкенд сайта отдаёт битой.

## [0.2.0] — 2026-09-05

Первый публичный выпуск.

### Добавлено

* **Вход в аккаунт по SMS-коду** вместо копирования кук из браузера:
  инструменты `auth_status` / `auth_send_code` / `auth_login` / `auth_logout`
  и команды `winelab-mcp login | status | logout`. Пароль не сохраняется —
  только сессионная кука.
* **Постоянная сессия** в файле с правами `0600`, по правилам ОС
  (`~/Library/Application Support`, `$XDG_CONFIG_HOME`, `%APPDATA%`).
  Переопределяется `WINELAB_CONFIG_DIR` и `WINELAB_SESSION`.
* **CLI** с выбором транспорта: `stdio` (по умолчанию), `http`
  (streamable-HTTP) и `sse` — сервер можно поднять один на несколько машин.
* Тесты: оффлайновый двойник сайта, проверка рукопожатия MCP в подпроцессе,
  и канарейка `tests/test_live.py` по настоящему winelab.ru (`WINELAB_LIVE=1`).
* CI на GitHub Actions: Linux/macOS/Windows × Python 3.10–3.14, сборка колеса,
  еженедельная проверка живого API.

### Исправлено

* **CSRF-токен не находился на живом сайте.** Искали `<meta name="_csrf">`,
  которого там нет — токен лежит в JSON-конфиге `ACC.config`. Из-за этого
  `cart_add` уходил без токена и получал `405`. Добавлен запасной источник —
  форма `/login/popup-form`.
* Параллельный `winelab-mcp login` в терминале больше не затирает сессию
  работающего MCP-сервера (и наоборот).

### Изменено

* Точка входа — `winelab_mcp.cli:main`; голый `winelab-mcp` по-прежнему
  поднимает stdio-сервер, как ожидают хосты.
* Ошибки различаются по `error_kind`: `blocked`, `auth`, `bad_input`, `error`.
